**Project:** "About Esteffany Ascencio" Resume Website
**Owner / Author:**  Esteffany Ascencio
**Date:** 2025-11-04
**Version:** 1.0

## 1. Overview
<!-- 
This is a brief description of the website and its overall purpose
-->
**Website Name:** About Esteffany Ascencio
**Purpose:** To provide information about Esteffany Ascencio, work experience, skillset,  and overall resume. The website will also allow users to send emails and continue onto LinkedIn profile.  
**Target Audience:** Hiring Managers and Recruiters for future jobs and internships.

## 2. Goals
<!-- 
Clearly state objectives/goals. These should be measurable or at least clearly defined.
-->
- Provide easy way for hiring managers to find me online.
- Display resume.
- Allow users to contact me for any questions or for opportunities.
- Showcase my work experience and skills.  
- Secure more job opportunities and interviews.  

## 3. Features
<!-- 
List the key features the website will have. Each feature should include a short description. 
-->
1. **Home Section**  
   - Welcome message and restaurant branding (logo, colors, tagline).  
   - Hero image of the restaurant or signature dishes.  

2. **Background Section**  
   - Full list of dishes categorized by appetizers, mains, desserts, and drinks.  
   - Prices for each item.  
   - Optional images for popular dishes.  

3. **Work Section**  
   - U-Haul Work Experience: What my role is and my responsibilities
   - Internship: What my role was and responsibilities.

4. **Skillset Section**  
   - Information on my skills
   - What I have experience in, with coding, Microsoft
   - Language skills
   - Include research papers I have made in different classes

5. **Resume**
   - Documented version of resume

6. **Contact Section**  
   - Address with embedded Google Maps.  
   - Phone number and email.  
   - Social media links - including Instagram, LinkedIn.  




## 4. User Stories
<!-- 
Who are the different visitors to the website, and how do they use the website?
-->
- **As a peer**, I want to view the website to find more information about my peer and find networking contacts.
- **As a Hiring Manager**, I want to find if Esteffany Ascencio has the qualifications for the position we are hiring for, based on skills and experience.  
- **As a mentor**, I want to offer advise on how to improve the website.

## 5. Design 
<!-- 
Include basic design and user experience considerations. You can include color schemes, fonts, layouts, etc.
-->
- **Brand aesthetic** Minimal, modern aesthetic with clean typography and ample white space.  
- **Color Scheme:** Minimal Color scheme with accent: #F88379, #FF8C00, #FFA000
- **Typography:** Red Hat Display for headings, Quicksand for body text.  
- **Navigation:** Top menu bar with links to Background, Work, Skillset, Resume Contact.  
- **Layout:** Simple, single-column scrolling pages with sections clearly separated.  
- **Images:** High-quality photos of me.  

## 6. Technical Stack / Tools
<!--
A note on what technologies will be used 
-->
- HTML5, CSS
- Optional: JS for interactivity (lightbox, smooth scroll)
- GitHub Pages for hosting
- Built with VSCode and GitHub Copilot assistance

## 7. Functional Requirements
<!-- 
What technical needs might need to be executed with the HTML/CSS + other technologies
-->
- Navigation bar with smooth scrolling to sections.   
- Lightboxes (fullscreen views) for images of dishes 
- External links open in new tabs.  
- Mobile menu (hamburger) for smaller screens.
- Fully responsive (mobile, tablet, desktop).  
- Cross-browser compatible (Chrome, Safari, Firefox).  
- Use semantic HTML5 tags and other approaches for SEO

## 8. Accessibility / UX Notes
<!-- 
Just a note to be sure we are considering all website users by making our websites more accessible
-->
- Alt text for all images
- High contrast for text readability
